# 3D可视化功能说明

## 概述
Electron前端现在包含完整的设备3D模型可视化，实时展示扫描过程中的设备运动状态。

## 新增3D模型组件

### 1. 机架系统 (Frame)
- **左侧支撑板**: 40×450×200mm 灰色喷漆
- **右侧支撑板**: 40×450×40mm 灰色喷漆  
- **底部横梁**: 830×40×40mm 灰色喷漆

### 2. 旋转总成 (Rotating Assembly)
- **主轴**: Ø35×600mm 抛光不锈钢
- **左侧轴**: Ø25×100mm 抛光不锈钢
- **右侧轴**: Ø25×150mm 抛光不锈钢
- **轴承座**: 50×80×80mm 哑光钢材 (×2)
- **联轴器**: Ø30×60mm 黑色阳极化
- **伺服电机**: 80×80×120mm 黑色

### 3. 导轨系统 (Linear Guides)
- **上导轨 (1#探头)**: 700mm×20mm 黑色精密导轨
  - 安装高度: Y = +35mm
  - 行程范围: X = -300 → +60mm
  
- **下导轨 (2#探头)**: 700mm×20mm 黑色精密导轨
  - 安装高度: Y = -35mm
  - 行程范围: X = +300 → -60mm

### 4. 探头组件 (Probe Assemblies)

#### 1#探头 (上方，绿色)
- **滑块本体**: 60×15×40mm 绿色 (#4ade80)
- **支架**: 20×40×20mm 哑光钢
- **表盘**: Ø15×10mm 白色
- **测量杆**: Ø3×40mm 抛光钢
- **测头**: Ø3球形 红色发光

#### 2#探头 (下方，蓝色)
- **滑块本体**: 60×15×40mm 蓝色 (#60a5fa)
- **支架**: 20×40×20mm 哑光钢
- **表盘**: Ø15×10mm 白色
- **测量杆**: Ø3×40mm 抛光钢
- **测头**: Ø3球形 红色发光

### 5. 模具 (Mold Surface)
- **形状**: 半圆柱体 (170°开口角度)
- **半径**: R200mm
- **长度**: 700mm
- **材质**: 半透明灰色 (40%透明度)
- **线框辅助**: 蓝色网格 (15%透明度)

## 实时动画功能

### 位置更新
系统通过WebSocket接收PLC数据，实时更新3D模型：

```javascript
function updatePosition(x1, x2, rot) {
    // 更新1#探头X轴位置
    if (carriage1Container) {
        carriage1Container.position.x = x1;
    }
    
    // 更新2#探头X轴位置
    if (carriage2Container) {
        carriage2Container.position.x = x2;
    }
    
    // 更新主轴旋转角度
    if (rotatingGroup) {
        rotatingGroup.rotation.x = THREE.MathUtils.degToRad(rot);
    }
}
```

### 扫描阶段可视化

#### APPROACH - 归位阶段
- 两个探头同步移动到起始位置
- 1#探头: 0 → -300mm
- 2#探头: 0 → +300mm

#### SCAN - 翻转扫描
- 主轴旋转: 0° ↔ 170° (往复)
- 探头测量杆接触模具表面
- 实时生成绿色/蓝色测量点

#### STEP - X轴进给
- 两探头向中心移动 (步长10mm)
- 1#探头: -300 → +60mm (左→右)
- 2#探头: +300 → -60mm (右→左)

#### COMPLETE - 完成
- 探头停止在终点位置
- 显示完整双色点云

## 灯光系统

### 环境光 (Ambient Light)
- **颜色**: 白色 #ffffff
- **强度**: 0.4
- **作用**: 整体场景基础照明

### 主光源 (Directional Light)
- **颜色**: 白色 #ffffff
- **强度**: 1.2
- **位置**: (200, 500, 200)
- **功能**: 启用阴影，主要照明

### 底部点光源 (Point Light)
- **颜色**: 蓝色 #4455ff
- **强度**: 0.5
- **位置**: (0, -200, 0)
- **作用**: 底部补光，增强立体感

## 相机控制

### 默认视角
- **位置**: (600, 400, 800)
- **目标**: (0, 0, 0)
- **视角**: 40° FOV
- **极角限制**: 0° ~ 120° (防止倒置)

### 交互控制
- **鼠标左键拖拽**: 旋转视角
- **鼠标滚轮**: 缩放
- **鼠标右键拖拽**: 平移
- **阻尼效果**: 启用 (系数0.05)

## 性能优化

### 渲染设置
- **抗锯齿**: 启用
- **像素比**: 最大2.0 (避免过高分辨率)
- **透明背景**: 启用
- **阴影贴图**: 启用
- **颜色编码**: sRGB

### 几何体优化
- 圆柱体段数: 32 (平衡质量与性能)
- 网格分辨率: 2000×40
- 点云大小: 3px (可见性与性能平衡)

## 使用建议

### 观察扫描过程
1. 连接PLC后，在3D视图中可看到完整设备模型
2. 点击"开始扫描"，观察：
   - 探头移动到起始位置（APPROACH）
   - 主轴旋转扫描（SCAN）
   - 探头进给移动（STEP）
   - 点云实时生成

### 调整最佳视角
- **俯视观察进给**: 使用"俯视图"按钮
- **侧视观察旋转**: 使用"侧视图"按钮
- **整体观察**: 使用"等轴视图"按钮

### 性能提示
- 大点云数据(>50000点)可能降低帧率
- 如需流畅动画，可隐藏模具网格

## 技术参考
- Three.js版本: r128
- OrbitControls: 标准轨道控制
- 渲染模式: WebGL + PBR材质
- 坐标系: 右手坐标系 (X右, Y上, Z前)
