# 手动操作指南

## 功能概述

前端界面现已集成完整的手动操作面板，参考下位机HMI界面设计，提供以下功能：

### 1. 点动控制
- **1#X轴、2#X轴、旋转轴** 的前进/后退控制
- 实时速度调节
- 按住按钮持续运动，松开立即停止

### 2. 定位动作  
- 输入目标位置，一键自动定位
- 自动速度优化（动作速度 = 点动速度 × 2）
- 到位自动停止

### 3. 回原点
- 单轴回原点（初始化）
- 整机初始化（所有轴同时回原点）

### 4. 实时监控
- 当前位置实时显示
- 进度条可视化
- 3D 模型同步更新

## 使用步骤

### 点动操作示例
1. 调整点动速度（如 1#X轴设为 200 mm/s）
2. **按住**"前进▶"按钮
3. 轴开始运动，实时观察位置
4. **松开**按钮，轴立即停止

**注意**: 点动是瞬时控制，必须持续按住才会运动

### 定位操作示例
1. 设置目标位置（如 1#X轴输入 -300）
2. 点击"定位"按钮
3. 轴自动移动到 -300mm 位置
4. 到达后自动停止

### 整机初始化流程
1. 点击"🏠 整机初始化"按钮
2. 确认对话框 → 确定
3. 所有轴依次返回原点：
   - 1#X轴 → -700mm
   - 2#X轴 → +700mm
   - 旋转轴 → 0°
4. 初始化完成后，状态指示灯变绿

## 安全提示

⚠️ **操作注意事项**:
1. 点动操作前，确认运动方向安全
2. 定位操作前，检查目标位置是否在行程范围内
3. 整机初始化会使所有轴运动，确保周围无障碍物
4. 遇到异常，立即点击"急停"或关闭软件

## 故障排查

### 点动按钮无响应
- 检查是否已连接PLC（状态指示灯为绿色）
- 检查浏览器控制台是否有错误信息
- 尝试刷新页面重新连接

### 定位动作无法执行
- 确认目标位置在允许范围内
- 检查轴是否处于报警状态
- 查看PLC是否已初始化完成

### 整机初始化失败
- 检查PLC通信状态
- 查看是否有轴处于报警状态
- 尝试单独对每个轴执行回原点操作

## 技术实现

### 前端 (Electron + Three.js)
- **renderer.js**: 实现点动按钮事件监听（mousedown/mouseup）
- **WebSocket 通信**: 发送 `write_coil` 和 `write_register` 命令
- **实时位置更新**: 同步更新UI和3D模型

### 后端 (Python + Modbus)
- **electron_ws_server.py**: 处理手动操作命令
- **hardware_driver.py**: 封装Modbus读写操作
- **modbus_sim_server.py**: 仿真PLC响应
