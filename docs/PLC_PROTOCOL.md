## 数据类型说明

| 类型 | 字长 | 说明 |
|------|------|------|
| Bool | 1 bit | 布尔型（线圈） |
| Int | 16 bit | 有符号整数（寄存器） |
| DInt | 32 bit | 双字整数（占用2个连续寄存器） |

## 使用示例

### 读取位置数据

```python
# 读取 1#X轴当前位置 (寄存器 2000, DInt 类型)
result = client.read_holding_registers(2000, 2, slave=1)
position_raw = (result.registers[0] << 16) | result.registers[1]
position_mm = position_raw * 0.01  # 精度转换
```

### 控制轴运动

```python
# 写入 1#X轴动作位置 (寄存器 41212)
target_position = int(50.0 / 0.01)  # 50mm
client.write_registers(41212, [target_position >> 16, target_position & 0xFFFF], slave=1)

# 启动运动 (线圈 1010)
client.write_coil(1010, True, slave=1)
```

### 初始化系统

```python
# 整机初始化 (线圈 104)
client.write_coil(104, True, slave=1)

# 等待初始化完成 (线圈 701)
while True:
    result = client.read_coils(701, 1, slave=1)
    if result.bits[0]:
        break
    time.sleep(0.1)
```

## 注意事项

1. **地址偏移**: Modbus 协议中寄存器地址需要减1（如协议中的2000，实际读取时为1999）
2. **字节序**: DInt 类型占用2个连续寄存器，高位在前
3. **从站地址**: 所有通信必须指定 `slave=1`
4. **心跳信号**: 建议每秒更新一次，用于检测通信是否正常
5. **精度转换**: 位置寄存器的值需要乘以 0.01 才能得到实际的 mm 值
